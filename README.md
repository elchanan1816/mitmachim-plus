# מתמחים+

אפליקציית Android עצמאית לפורום [מתמחים טופ](https://mitmachim.top), ב־Kotlin וב־Jetpack Compose / Material 3. קוד המקור כאן הוא גרסה **0.2.13** (`versionCode 29`). זו גרסת בדיקה עם אותן תכונות כמו 0.2.12.

פותחה על ידי **@רב יהודה פרחים**, בסיוע **@הבריסקער רב**, מפורום מתמחים טופ.

## מה כלול

- בית, קטגוריות, דיונים, חיפוש ופרופילים; ממשק עברי ו־RTL.
- תצוגת דיון רגילה ותצוגת צ׳אט אופציונלית, תגובה בהחלקה, תיוגים, טיוטות וספוילרים.
- פעולות חשבון ופרסום בכפוף להרשאות שרת הפורום.
- תמיכה בתעודות CA ציבוריות של נטפרי, המוגבלת לדומיין הפורום. אין ביטול של אימות TLS או אמון גורף בתעודות משתמש.
- בדיקת עדכונים מתוך הפוסט הראשון בשרשור ההפצה; אימות קריפטוגרפי של ה־APK לפני התקנה. בדיקה אוטומטית כבויה כברירת מחדל.

## בנייה מקומית

נדרשים JDK 17 ומעלה ו־Android SDK 36. מגדירים `ANDROID_HOME` או קובץ `local.properties` מקומי עם `sdk.dir`. ה־Gradle Wrapper המצורף משתמש ב־Gradle 8.14.3.

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

ב־Windows משתמשים ב־`gradlew.bat`. בדיקות מכשיר דורשות מכשיר/אמולטור מחובר:

```sh
./gradlew :app:connectedDebugAndroidTest
```

בניית Debug משתמשת במזהה נפרד עם סיומת `.debug`, כדי לא להחליף את התקנת ההפצה. Android 7.0 / API 24 ומעלה נתמך.

## חתימה ועדכונים

**מפתח ה־release והסיסמה אינם כלולים במאגר.** לבניית Release חתום מגדירים מקומית `MITMACHIM_RELEASE_STORE_FILE` ו־`MITMACHIM_RELEASE_PASSWORD`, ומשתמשים ב־alias `mitmachim-release`. הסקריפט `scripts/build-release.ps1` מבקש סיסמה באופן מוסתר אם אינה מוגדרת.

אפשר לבנות Debug ולבחון את הקוד ללא מפתח ההפצה. בנייה עם מפתח אחר אינה עדכון חתום לגרסה הרשמית הקיימת, והמנגנון הרשמי לא יקבל אותה. טביעת אצבע של תעודת חתימה ציבורית בקוד אינה המפתח הפרטי ואינה מאפשרת לחתום במקומו.

ראו [הפצת עדכונים](UPDATE-CHANNEL.md), [תמיכת נטפרי](NETFREE-CERTIFICATES.md) ו־[אבטחת המאגר](SECURITY.md).

## פרטיות ומגבלות

אין במאגר חשבונות משתמשים, סיסמאות, cookies או נתוני גלישה. האפליקציה מתקשרת ישירות עם הפורום; אין backend נוסף או analytics. הרשאות ואימות חשבון נקבעים בשרת. כניסה לאתר באמצעות Google בדפדפן אינה כניסה אוטומטית ללקוח ה־API המקומי.

105 בדיקות JVM עברו במקור שעליו גרסה זו מבוססת. בדיקות מכשיר ותאימות לכל רשת נטפרי לא הושלמו; אין הבטחה להתנהגות נטולת תקלות בכל מכשיר.
